# 论文源数据查重规范

本规范审查 Excel 中的数值源数据。它用于发现复用、录入错误和需要追溯的数值模式，不用于判断图像重复，也不能单独证明学术不端。

规则版本为 `1.0.0`。阈值是可调整的筛查设置，不是经过校准的统计显著性界限。默认设置见 [default-settings.json](default-settings.json)，执行方法见 [usage.md](usage.md)。

## 1. 检查单位与证据边界

### 1.1 分组与样本

每个比较单元对应一个明确的实验组和指标。工作表通常对应主图，粗框通常对应子图。脚本不会把这些排版线索自动当成实验事实。

同一组数据可以纵向或横向排列，也可以分散在长表中。分组映射记录工作表、子图、组名和单元格。新工作簿必须重新检查映射，不能复用另一份数据的位置和结论。

只有相同 `comparison_set` 的组参与比较。该字段表示本次允许比较的指标范围。不同单位或无关指标应分开；跨图、跨工作表的同类指标可以放在同一集合。不得在看到命中后，单纯为消除结果而缩小集合。

主要分组用于覆盖源数据。辅助分组用于样本轨迹等补充比较。同一个测量值只能归属一个主要分组，但可以同时进入辅助轨迹。比较单元数不等于独立样本量。

### 1.2 原始值与精度

精确比较读取 XLSX 内部保存的十进制数值。Excel 显示的四舍五入结果不作为精确重复依据。脚本不会把文本型数字默默转换为测量值。

数值相同与测量精度是不同概念。例如，`1.230000` 的有效小数位为 2，`1.000000` 为 0。显示格式增加的零，不增加有效精度。分数、归一化和共同分母也可能产生相同的长小数。

默认高精度规则要求有效小数位至少为 3。如果需要严格执行“小数位数大于 3”，将 `high_precision_decimals` 设为 `4`。该规则要求整个存储数值相同，不只是小数部分或前三位相同。

### 1.3 覆盖与排除

所有数值、公式和 Excel 错误单元格都必须归属主要分组，或有明确排除理由。时间轴、剂量、数字 ID、日期、汇总统计及计算中间值应按实际用途处理。

公式默认不能作为原始测量值。明确纳入公式时，脚本只检查保存的数值缓存，不运行或重算公式。缓存缺失时应重新保存工作簿，或说明原因后排除。所有转换应使用副本。

覆盖完整仅表示单元格归属完整，不表示样本身份、单位、仪器记录和实验设计已经核验。隐藏页也进入覆盖检查。

## 2. 重复类型与模拟示例

所有示例都来自 `assets/demo/demo.xlsx`，与真实研究数据无关。完整预期结果见 `assets/demo/expected.json`。工作表 `Columns` 的列名就是示例组名。

### 2.1 跨组数值复用

| 类型 | 脚本代码 | 模拟对象 | 判断方式 |
| --- | --- | --- | --- |
| 整组同序重复 | `exact_ordered` | `base` 与 `exact-copy` | 10 个值相同，顺序及空白位置一致 |
| 整组乱序重复 | `exact_unordered` | `base` 与 `shuffled-copy` | 10 个值和重复次数相同，顺序不同 |
| 部分精确重复 | `exact_partial` | `base` 与 `partial-copy` | 6/10 个值完全相同，两组覆盖率均为 60% |
| 高精度相同值 | `high_precision` | `precision-a` 与 `precision-b` | 两个六位小数值相同，尚未达到大量重复条件 |
| 同序近似重复 | `near_ordered` | `base` 与 `near-copy` | 同位置值约相差 0.3%，同时通过波动尺度检查 |
| 无序近似重合 | `near_unordered` | `base` 与 `near-shuffled` | 乱序后约相差 0.4%，采用一对一匹配 |

例如，`base` 的前 3 个值为 `1.123456、2.234567、4.345678`。`exact-copy` 完整复用这些值。`shuffled-copy` 打乱顺序，仍然保留每个值的出现次数。`partial-copy` 只保留前 6 个值，其余 4 个值不同。

精确匹配采用多重集合。一组出现 3 次的 `1.123456`，只能匹配另一组中实际存在的次数。无序近似匹配也不允许同一个点被重复使用。

单个高精度相同值只构成线索。默认同一组对达到 3 个高精度匹配点时，提升复核顺序；该数量不是显著性检验。规则命中可以重叠，不能把命中次数相加为独立问题数。

### 2.2 变换后的复用

| 类型 | 脚本代码 | 模拟对象 | 模拟关系 |
| --- | --- | --- | --- |
| 精确平移 | `offset` | `base` 与 `offset-copy` | `y = x + 3.5` |
| 精确缩放 | `scale` | `base` 与 `scale-copy` | `y = 2x` |
| 精确线性变换 | `affine` | `base` 与 `affine-copy` | `y = 1.7x + 2.25` |
| 近似平移 | `near_offset` | `base` 与 `near-offset` | 固定平移后加入小扰动 |
| 近似缩放 | `near_scale` | `base` 与 `near-scale` | 缩放比例有小幅变化 |
| 近似线性变换 | `near_affine` | `base` 与 `near-affine` | 线性变换后加入更小扰动 |

这些关系按原表位置拟合，不删除空白后重新对齐。两组至少需要 5 个点，且位置能够对齐。声明为无序的数据不执行变换拟合。

单位换算、背景扣除、标准化和同一数据的派生指标都可能合法产生变换关系。高相关系数本身不足以证明复制。应核对计算公式和原始导出记录。

### 2.3 组内规则化模式

| 类型 | 脚本代码 | 模拟对象 | 具体表现 |
| --- | --- | --- | --- |
| 等差序列 | `arithmetic` | `arithmetic` | 从 `100.25` 起，每次增加 `0.75` |
| 近等差序列 | `near_arithmetic` | `near-arithmetic` | 等差序列上加入小扰动 |
| 等比序列 | `geometric` | `geometric` | 从 `0.125` 起，每次乘以 `1.5` |
| 近等比序列 | `near_geometric` | `near-geometric` | 等比序列上加入小扰动 |
| 末位数字集中 | `terminal` | `terminal` | 10 个值的小数第 2 位均为 `7` |

组内序列规则不是跨组重复。它们属于辅助检查，应与跨组复用分开解释。排序、时间趋势、设定值、稀释梯度和仪器分辨率都可能产生规则化模式。

末位规则分别统计小数第 2、3、4 位。只有有效小数位足够的数值进入对应位置的分母。脚本不补零，也不先取整。它不检验所有可能的末尾字符串，不使用本福特定律，更不输出“造假概率”。

### 2.4 成套记录与元数据

| 类型 | 脚本代码 | 模拟位置 | 具体表现 |
| --- | --- | --- | --- |
| 成套记录重复 | `duplicate_record` | `Records` 第 2、3 行 | 两个测量指标均相同，样本 ID 不同 |
| 成套记录近似 | `near_record` | `Records` 第 6、7 行 | 两个指标均近似，同时通过各列波动尺度检查 |
| 唯一记录键重复 | `duplicate_id` | `Records` 第 4、5 行 | 映射要求唯一，但 `S03` 出现两次 |
| 稳定字段冲突 | `metadata_conflict` | `Records` 第 4、5 行 | 相同 ID 的组别和性别不同 |
| 派生关系不一致 | `derived_mismatch` | `Derived!D7` | 声明的两步差分与保存值不一致 |

记录表必须明确列出指标列、身份键和稳定字段。没有样本 ID 时，可以检查成套数值复用，但样本身份冲突无法评估。缺少字段或存在空白时，只报告实际可检查的范围。

唯一键可以是“样本 ID＋访视时间＋技术重复编号”。纵向随访、交叉试验和技术重复可能合法复用样本 ID。稳定字段也由研究设计决定，不能默认治疗组在所有时间点都不变。

当前脚本只实现显式声明的滞后差分关系：`target[i] = source[i] - source[i-lag]`，前 `lag` 个点使用基线 0。它不是通用公式验证器。`confirmed` 表示已有依据；`hypothesis` 表示待证实假设。假设不一致不能直接定性为数据错误。

### 2.5 必须保留的反例与解释

模拟数据还包含以下反例，用于防止误判。

- `low-variance-a` 与 `low-variance-b`：两组都在 100 附近，相对差异不到 1%，但差异远大于组内波动，不应判为近似复制。
- `counts-a` 与 `counts-b`：大量 0、1、2 可以完全重合，但信息量低，不额外高亮为优先问题。
- `gap-a` 与 `gap-b`：去掉空白后数值相同，原表空白位置不同。只能报告无序相同，不能报告同序复制。
- `Horizontal`：用合并表头和横向范围展示不同排版，不把横排数据忽略。
- `Time`：同一测量矩阵既按时间切片覆盖，又按辅助轨迹比较。切片重合与轨迹关系分别解释。
- 共享对照：通过 `reuse` 声明理由和证据，保留命中记录，改为绿色解释项。不能仅因组名相同就自动认定合理复用。

## 3. 默认计算口径

### 3.1 完整与部分精确重复

设两组分别包含 `nA`、`nB` 个有效点，一对一精确匹配数为 `m`。

```text
覆盖率 A = m / nA
覆盖率 B = m / nB
较小组覆盖率 = m / min(nA, nB)
```

完整重复要求 `m = nA = nB`，且较小组至少有 4 个点。部分重复要求匹配至少 5 个点，较小组覆盖率至少为 60%。报告始终保留两组覆盖率，不把小组完全嵌入大组描述为“两组全部相同”。

整数、零值、常量和同一时间矩阵切片的重合会降级。整数不是自动排除项：如果完整组有至少 4 个不同数值，且最常见值占比低于 60%，仍可能需要优先复核。

### 3.2 百分比近似与低波动护栏

每对数值的相对误差定义为：

```text
e(a, b) = |a - b| / max(|a|, |b|)
e(0, 0) = 0
```

默认允许单点相对误差不超过 1%。覆盖率门槛为 90%，相似度门槛为 99%。同序规则对全组对应位置计算平均相对误差；无序规则对实际匹配点计算平均误差。

```text
匹配点相似度 = 1 - mean(e)
稳健尺度 s = 1.4826 × median(|x - median(x)|)
当 s 为 0 时，改用总体标准差
合并尺度 = sqrt((sA² + sB²) / 2)
尺度误差 = 匹配点平均绝对误差 / 合并尺度
```

尺度误差必须不超过 25%。两组都为常量时，不使用百分比近似规则。纯整数的近似重合也不执行，精确重复和变换关系仍保留。

无序规则先最大化一对一匹配数量，再在排序约束下最小化总相对误差。它要求至少匹配 5 个点，并覆盖较小组的 90%。如果大组覆盖率不足 90%，应称为“近似片段重合”，而不是两组整体近似。

无序匹配可能只说明分布相近。大量来自同一分布的数据尤其容易产生近似匹配。因此，相似度必须与覆盖率、原顺序、样本 ID 和实验关系一起解释。

上述尺度指标对共同的单位倍数变化保持不变，但对加上共同常数不保证不变。接近 0 的数据不能任意加常数来满足门槛，应检查原始量纲和数据生成过程。

### 3.3 变换、序列与末位

| 检查 | 默认条件 |
| --- | --- |
| 近似线性变换 | 拟合残差均方根／组内总体标准差不超过 0.1% |
| 近似平移 | 中位数平移后的归一化残差不超过 5% |
| 近似缩放 | 比值变异系数不超过 2%，归一化残差不超过 5% |
| 近等差 | 相邻差分变异系数不超过 5%，线性趋势归一化残差不超过 5% |
| 近等比 | 相邻比值变异系数不超过 2%，对数线性趋势归一化残差不超过 5% |
| 末位集中 | 对应位置至少有 8 个有效值，某个数字占比至少为 80% |

变异系数为标准差除以均值的绝对值。均值为 0 时不使用该变异系数。等比规则只检查正值。常量和存在内部空白的序列不执行这些序列规则。

精确平移、缩放和线性关系使用十进制计算。近似拟合使用浮点计算。所有拟合都属于筛查，不替代测量误差模型。

### 3.4 成套记录

成套记录比较至少需要 2 个映射声明的测量指标。完整相同按所有指标存储值一致判断。近似记录使用相同的相对误差和相似度门槛，同时检查每个指标的表内波动尺度。

缺失指标行不参加成套比较，报告会列出遗漏数量。纯计数型指标的成套重合也可能来自巧合，需人工解释；这里的“记录复核”颜色不是不端判定。

## 4. 高亮与结果表述

高亮采用分类颜色。一个单元格命中多个规则时，显示优先级最高的颜色，所有命中仍在明细中保留。

| 颜色 | 类别 | 含义 |
| --- | --- | --- |
| 红色 | `priority` | 信息量较高的完整组重复，优先追溯 |
| 黄色 | `metadata` | 唯一键重复或稳定字段冲突 |
| 橙色 | `review` | 多点重复、变换、序列、成套记录或派生复核 |
| 紫色 | `precision` | 高精度单点／少量匹配，或末位集中 |
| 蓝色 | `near` | 同序或无序近似线索 |
| 绿色 | `explained` | 已提供依据的共享数据或派生关系 |
| 不额外着色 | `low` | 整数、零值、常量等低信息量重合 |

颜色不是一一对应的重复类型。类型名称、匹配点、覆盖率和解释以“查重明细”为准。默认模拟文件没有声明共享对照，因此绿色由单独的共享对照测试展示，不伪造“已有证据”的说明。

优先追溯整组复用，其次追溯多点高精度重合、成套记录和不一致的身份信息。末位集中、趋势和近似关系可以提示进一步检查，但不能据此删除数据或修改结果。

结论应写“发现某种模式，需核对某项证据”。无命中时写“在已映射范围和本次阈值下未发现对应模式”。不要写“数据绝对真实”或“排除造假”。

## 5. 验证与局限

脚本写入独立副本。它保留原始工作表 XML，只修改高亮位置的样式索引。报告页追加到原工作表之后，避免改变局部命名区域的工作表索引。

每次输出验证输入 SHA-256、原始值和公式、源工作表内容及高亮填充。报告保留实际映射、参数和输出哈希。SHA-256 是文件校验值，不是实验真实性证明。

原有条件格式可能覆盖填充显示，受保护的工作表也可能限制查看操作。具备 Excel 或表格渲染能力时，应检查重点区域。不要为了显示颜色而破坏原条件格式。

脚本不检测图像、任意公式、所有拼接方式或全部统计异常。它不校准多重比较，不输出 p 值，不能确认测量值是否来自独立实验。数据缺失、组别误识别和错误排除都会影响结果。

默认组对比较上限为 200,000，近似匹配矩阵上限为 250,000 个元素。超限必须报告未完成范围；不能写“未发现”。可以按科学上合理的指标分批，或调整设置后重跑。

本规范的规则和阈值来自本次源数据复核需求及实现约定，未声称引用某篇论文或国家标准。方法使用公开的数学定义，经验阈值需要结合实验背景调整。
